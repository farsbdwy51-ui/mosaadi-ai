# مساعدي AI — المساعد الشخصي الذكي

مساعد شخصي صوتي بالعربية (مصري وفصحى) يعمل كاملًا داخل المتصفح: يستمع، يفهم، يخطط، ينفّذ، ويتذكر — وبياناتك كلها على جهازك أنت.

## المميزات

- **🎙️ صوتي أولًا**: زر ميكروفون كبير، تحويل الكلام إلى نص والرد بالصوت عبر Web Speech API المدمجة في المتصفح — مجانًا وبدون خوادم.
- **🧠 حلقة وكيل حقيقية**: كل طلب يتحول إلى خطة خطوات تُنفَّذ بالترتيب مع التحقق وإعادة المحاولة ضمن حدود آمنة، ثم تقرير نهائي.
- **🛠️ أدوات تعمل فعلًا من المتصفح**:
  - بحث في الإنترنت (ويكيبيديا عربي/إنجليزي — مجاني)
  - توليد الصور (Pollinations — مجاني بدون مفتاح)
  - تحويل قصة إلى سيناريو مشاهد
  - كتابة وتشغيل كود JavaScript واكتشاف أخطائه (بيئة معزولة داخل المتصفح)
  - إنشاء ملفات (Markdown / نص / CSV) وتنزيلها
  - أفكار وسكربتات محتوى يوتيوب
  - فتح روابط
- **💾 ذاكرة تحت سيطرتك**: عرض وإضافة وتعديل وحذف، مقسّمة لتصنيفات (أسلوب الكلام، مشاريع، مهام، أدوات ومشاكل، عام).
- **📋 سجل مهام**: كل طلب بحالته (منفّذة ✅ / فاشلة ❌ / متوقفة ⏹) مع خطواته وتقريره.
- **⏹ زر إيقاف فوري**: يوقف الصوت والتنفيذ في اللحظة.
- **⚙️ صفحة إعدادات**: مفتاح OpenRouter، اللغة، سرعة الصوت، وحالة كل الاتصالات.
- **📱 PWA**: قابل للتثبيت على الشاشة الرئيسية في Android، ويعمل دون اتصال بعد أول تحميل.
- **🔒 خصوصية**: لا تسجيل صوت، لا خوادم وسيطة، لا مفاتيح داخل الكود — كل شيء في localStorage على جهازك ويمسح بزر.

## التشغيل

يحتاج فقط Node.js (18 أو أحدث). لا توجد أي مكتبات للتثبيت.

```bash
npm start
# ثم افتح http://localhost:8080
```

أو أي خادم ملفات ثابتة:

```bash
npx serve .
```

> **مهم**: الميكروفون يتطلب HTTPS أو localhost. على الهاتف افتح النسخة المنشورة (انظر النشر بالأسفل) أو شغّله على نفس الشبكة عبر HTTPS.

## الاختبارات

```bash
npm test
```

42 اختبارًا تغطي: تحليل النية العربية، بناء الخطط، تنفيذ الوكيل (نجاح/فشل/إعادة محاولة/إيقاف)، مخزن الذاكرة، سجل المهام، والدوال النقية للأدوات.

وفحص تفاعلي حقيقي للواجهة عبر Chrome:

```bash
npm start &
node scripts/smoke-test.mjs
```

## النشر (رابط عام مجاني)

المشروع ملفات ثابتة 100% — يعمل مباشرة على GitHub Pages:

1. ارفع المستودع إلى GitHub.
2. Settings → Pages → اختر الفرع `main` والمجلد الجذر.
3. الرابط يصبح `https://<اسمك>.github.io/<المستودع>/` — ويعمل عليه الميكروفون لأنه HTTPS.

## النموذج الذكي (اختياري)

بدون أي مفتاح يعمل المساعد بقواعد عربية مدمجة. لعقل أذكى (تخطيط أعقد، كتابة مستندات وكود):

1. أنشئ مفتاحًا مجانيًا على [OpenRouter](https://openrouter.ai) (توجد نماذج مجانية).
2. افتح **الإعدادات** داخل التطبيق والصق المفتاح.

المفتاح يُحفظ على جهازك فقط ويُرسل مباشرة من متصفحك إلى OpenRouter.

## حدود صادقة

هذه الأشياء **لا يمكن** لتطبيق ويب في المتصفح تنفيذها (قيود أمنية في المتصفح نفسه)، ومواضعها جاهزة في الإعدادات عند ربط خدمة خارجية:

| الطلب | الحالة |
|---|---|
| التحكم الكامل في الهاتف | يحتاج تطبيق Android أصلي بخدمات إمكانية الوصول |
| توليد فيديو | يحتاج خدمة خارجية (لا توجد مجانية موثوقة) |
| البريد والتقويم | يحتاج ربط حساب Google بصلاحيات OAuth |
| رفع فيديوهات يوتيوب | يحتاج ربط قناة عبر YouTube API |
| التخزين السحابي | يحتاج ربط Google Drive أو بديل |

المساعد لا يدّعي تنفيذها — يقول بوضوح إنها تحتاج خدمة خارجية.

## بنية المشروع

```
mosaadi-ai/
├── index.html            # الواجهة (عربي RTL)
├── css/style.css         # التصميم الداكن
├── js/
│   ├── app.js            # ربط الواجهة بكل الوحدات
│   ├── agent.js          # حلقة الوكيل: فهم → خطة → تنفيذ → تقرير
│   ├── tools.js          # سجل الأدوات + الدوال النقية
│   ├── speech.js         # الصوت: استماع + نطق
│   ├── memory.js         # مخزن الذاكرة
│   ├── tasks.js          # سجل المهام
│   ├── settings.js       # الإعدادات والاتصالات
│   └── llm.js            # موصّل OpenRouter (اختياري)
├── tests/                # 42 اختبارًا للنواة (node:test)
├── scripts/smoke-test.mjs # فحص واجهة حقيقي عبر Chrome
├── server.js             # خادم ثابت بدون مكتبات
├── sw.js                 # Service Worker للعمل دون اتصال
└── manifest.webmanifest  # تعريف PWA
```

## الأمان

- لا تُنفَّذ الأكواد إلا داخل Web Worker معزول بمهلة 5 ثوانٍ.
- الحذف (ذاكرة/سجل) يتطلب تأكيدًا دائمًا.
- لا توجد أي أسرار أو مفاتيح في الكود — `config.js` مستبعد في `.gitignore`.
